# Smart Hospital & Resource Allocation System

A modular, menu-driven Smart Hospital Patient & Resource Allocation System built in C for the CSC 1012 assignment.

## Features
* Patient intake and triage sorting 
* Bed occupancy tracking using a 2D array
* Automated billing, surcharges, and age-based subsidy discounts
* Performance reports and file handling

## How to Run
1. Open the project folder in **Code::Blocks**.
2. Build and run the project as a console application.
